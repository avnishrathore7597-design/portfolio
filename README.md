# Avnish Rathore Portfolio

A responsive, static portfolio website made with HTML, CSS, and vanilla JavaScript.

## Files

- `index.html` - page content and embedded Google contact form
- `styles.css` - layout, styling, and responsive design
- `script.js` - mobile navigation and footer year
- `favicon.svg` - browser tab icon
- `portfolio contacts.xlsx` - local workbook; it is not automatically connected to Google Forms

## Preview locally

Open `index.html` in a browser. To test the contact form, serve the folder over HTTP (for example, with the VS Code Live Server extension) because browser security rules can block cross-origin requests from a `file://` page.

## Contact form and responses

The contact section embeds the Google Form provided for this portfolio. Its response destination and notification settings are managed by that form's owner in Google Forms.

- [Open the contact form](https://forms.gle/dUzyp4pmTyoMskim8)

The previously created **Portfolio Contacts** Google Sheet was linked to the earlier form and may not receive responses from this replacement form. The local workbook is an offline file and does not sync with either Google Form or Google Sheet.

## Publish the website

Upload the complete `avnish-portfolio` folder to any static web host, such as GitHub Pages, Netlify, or Vercel. No build step or package installation is required. The embedded Google Form requires an internet connection and visitors must be able to access Google Forms.
